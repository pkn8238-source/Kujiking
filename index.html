    판 고르기

    번호 선택

    뽑고 싶은 번호를 직접 고르세요. 고른 번호는 바로 개봉 대기 상태가 됩니다.

    교환 코드 입력

    당첨 확인

    결과는 ‘당첨 내역’에 저장되고, 상품은 스마트스토어 주문으로 발송됩니다.

공정성 검증

결과는 판이 열리기 전에 봉인됩니다. 공개된 해시와 시드로 누구나 직접 확인할 수 있어요.

01

시드 생성 · 해시 봉인

판을 만들 때 무작위 시드를 생성하고, SHA-256 해시를 판매 전에 공개합니다.

02

번호별 결과 고정

각 번호의 SHA-256(시드:번호) 값을 정렬해 상품을 배치합니다. 해시는 단방향이라 미리 알 수 없어요.

03
